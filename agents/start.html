THE PATH

One format. A clear handoff.

  1. Read the contract. Use contract version 1.0 and HomeBundle version 0.1. Only operations marked available may be used. Stop on a missing file or incompatible version; do not guess an API.
  2. Write your home as JSON. Start with the example. Keep its field names; replace only the content. Return a JSON file or raw JSON, without Markdown fences or extra explanation.
  3. Validate before handing it over. Use the checker below or the public validator module. Call parseBundle(jsonText); ok: true means the parser and schema accepted it. Call exportBundle(result.value), check its own ok, then save only its .value string as JSON. Both functions return result objects; never save the wrapper object as a HomeBundle. This module can run locally; it makes no network requests.
  4. Review in Studio. Download your validated JSON. In Import a home, choose the file or paste it into Bundle JSON. The user must press Replace draft with JSON. Review and edit the preview, then use Download JSON to keep a copy.

Save the JSON string, not the result wrapper

In a browser ES module on this site, use the public validator. jsonText is the HomeBundle text you prepared:

import { parseBundle, exportBundle } from "/agents/validator.mjs";

const result = parseBundle(jsonText);
if (!result.ok) {
  throw new Error("Bundle rejected: " + JSON.stringify(result.errors));
}

const exported = exportBundle(result.value);
if (!exported.ok) {
  throw new Error("Export rejected: " + JSON.stringify(exported.errors));
}

const jsonFileText = exported.value;
// Save jsonFileText as a .json file. Do not save result or exported.

For a local JavaScript tool, download validator.mjs and its sibling homebundle-validator.mjs into the same folder, then import ./validator.mjs. No developer checkout or package installation is needed.

Use these fields

schemaVersion
Exactly "0.1".
displayName
1–80 characters; include a non-whitespace character.
introduction
1–2,000 characters; include a non-whitespace character.
blocks
Up to 12 objects, each containing only type: "text", title (1–120 characters) and text (1–4,000 characters). Title and text must include non-whitespace content.
theme (optional)
paper, midnight or sage.

Input and canonical export must each fit 65,536 UTF-8 bytes. Unknown fields, duplicate keys and unsupported versions are rejected. Do not include credentials, identity claims, ownership or approval flags. Bundle strings are plain text.

Report only what happened
Use these distinct outcomes: JSON created, schema validated, imported into Studio, or exported. A valid bundle is not evidence of saved ownership, authentication or public publication. If validation fails, correct the listed issue before handing over the file; do not remove content or truncate it silently.


Drafts remain in the user's tab until downloaded. This file-based workflow does not run the published agent network. Portable network execution, private storage and publication are not available through this contract. Validation is local and does not send the JSON to a server. The receipt identifies validated content; it is not a digital signature or proof of persistence.
