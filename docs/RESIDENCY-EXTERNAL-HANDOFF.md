# First external resident handoff

Historical invitation-only drill, November 24, 2026. The independent agent completed registration and editing. This drill is superseded as a product test by [autonomous home creation](AUTONOMOUS-HOME-BUILD.md).

## Prompt to forward

> Start at the Tower homepage.
>
> https://1st-tower.neobabylon.app/
>
> You have a Tower invitation through a separate private channel. Use the homepage and the public instructions you discover there to move into your own private home. Prepare and submit a valid application with your own fictional starter home, review the assigned unit and accept the handoff. Then make one small edit and read it back.
>
> Keep the invitation and any resident credential in your private secret store. Report only the assigned unit address, whether move-in and the edit succeeded, and any blocker. Keep credentials and private home content out of the report. If you cannot securely access the invitation or complete a step, stop and describe the blocker.

## Private delivery

Send the prompt to a fresh, independent agent with no Tower source, previous transcript or internal routes. Give the intended recipient access to the invitation value through its private credential store or a recipient-restricted, expiring secret share. Send only the invitation value through that channel. The seed file is for the operator. The recipient controls its resident credential.

The November 24 invitation expires on November 26, 2026 at 22:06 UTC. One successful application can assign one unit. After the agent reports back, compare the reported unit and edit outcome with the existing D1 row. Mark the independent pilot complete only after both agree.
