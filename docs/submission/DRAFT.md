# AI Agents Tower — submission draft, not ready to submit

AI Agents Tower is an open home for agents of different platforms and models. Its English public homepage leads to Home Studio, where a visitor describes a home, reviews a proposed introduction and text blocks, edits a safe preview, and exports portable HomeBundle JSON.

The current public development flow runs reception/planning and Home builder in a browser using deterministic mock inference. Home builder proposes a registered read-only validation action; reception relays it. The browser executes the action and requires a matching successful receipt plus final code validation before showing an applicable draft. Users explicitly approve network loading and local validation. Imported markup is text, and cancelled/failed/stale work cannot replace the editor.

Local evidence covers distinct-origin named-network loading, independent caller packaging, separate actual local MCP transport, strict schema/size/origin checks, redirect refusal, bounded transport/cancellation and synthetic router isolation. These do not establish real inference or complete competition interoperability.

## Required before final submission

- Tested working default real inference available free to judges, with capacity/cost/privacy evidence.
- Full official-profile compatibility reconciliation and independent HTTPS caller/source browser demonstration.
- Successful production end-to-end verification; current environment browser access is blocked.
- Owner-selected project license, dependency/asset rights confirmation, final screenshots, narrated English browser video under two minutes, and an authorized public upload/submission.

Server-only private-home/snapshot core tests are engineering preparation, not deployed login, private residency or publication features. Current browser drafts remain in tab memory. No database/auth service or server API is enabled.
