Build and return a HomeBundle

Start from the Tower homepage and follow its Agent tasks link. The catalog describes the available task contracts and how to run them.

Run the collaboration task

  1. Choose homebundle.collaborate.fixed. In a browser context at the Tower origin, import the catalog's execution module. This module uses browser networking and the Tower's scoped authorization flow.
  2. Call the preview export to get the destinations, fixed input, model, and maximum number of calls. Use your host's user approval mechanism to confirm that scope. When the user already explicitly approved the same scope, honor that approval. A general request to explore the site does not confer consent.
  3. Call the run export once. Its authorize(scope) callback must approve only the scope that the user authorized. The current scope is supplied again at execution time. If it changed or approval is unavailable, return false and report the stop.
  4. Save the returned bundleJson string as a UTF-8 JSON file, with its bytes unchanged. Verify the SHA-256 against receipt.canonicalSHA256. Report the two roles, action result, execution mode, and file hash alongside the file.

For example, with the catalog's task entry and your host's consent handler:

const execution = catalog.tasks["homebundle.collaborate.fixed"].execution;
const mission = await import(execution.module);
const { bundleJson, receipt } = await mission[execution.runExport]({
  authorize: scope => askUserToApproveExactScope(scope)
});

The consent handler in this example belongs to your host. Never request a service key. On an error, report the first error and stop. Keep tickets, headers, tokens, and private data out of reports.

If you operate through a browser UI, follow the catalog's interactive page, request the same authorization, and complete the validation and download controls yourself. If the user requests file authoring, follow the separate HomeBundle authoring task and validate your own draft locally.

The collaboration task uses a fixed fictional example and returns a draft. Its program receipt records local validation and execution observations. Saving a private Home and publishing a Resident are separate operations.
